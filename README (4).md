# Studi Kasus 1 — Analisis Nilai Mahasiswa

## Deskripsi
Program menghitung nilai akhir mahasiswa berdasarkan bobot Tugas 30%, UTS 30%, dan UAS 40%. Program menampilkan ranking, mahasiswa berprestasi (nilai akhir di atas 80), dan mahasiswa terbaik.

## Konsep Python
- **List comprehension** untuk membentuk data hasil analisis.
- **Lambda function** sebagai fungsi kunci pada `sorted()` dan kondisi `filter()`.
- **Filtering** untuk memilih mahasiswa dengan nilai akhir di atas 80.
- **Sorting** untuk mengurutkan nilai dari tertinggi ke terendah.

## Cara Menjalankan
Pastikan Python 3 sudah terpasang, lalu jalankan dari folder ini:

```bash
python main.py
```

Bukti eksekusi tersedia pada `output.png`.
